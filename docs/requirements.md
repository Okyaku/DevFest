プロジェクト名：AI Closet
〜画像解析で「持っている服」を資産に変える、次世代スタイリング・ログ〜

1. コンセプト
   「持っているのに着ていない」をゼロにする。
   スマホでクローゼットをスキャンして持ち物をデジタル化。日々の着用記録から算出される「使用統計」に基づき、AIが死蔵している服を活かしたコーディネートを提案。賢い着回しと断捨離を同時に叶えるサービスです。
2. ターゲット
   毎朝、クローゼットの前で「着る服がない」と立ち尽くしている人。
   自分がどの服をどれくらい着ているか、客観的な数値で知りたい人。
   買ったまま忘れている服（タンスの肥やし）を有効活用したい人。
3. 解決する課題
   毎日着る服を考えるのに時間を使っていること
   着てない服がよくわからない
   きている服や色が同じものばかりになっている気がする
   持っている服の把握が大変
   自分の持っている服の組み合わせが似合うかどうかわからない
   ↓
   着回しを減らして、「毎日同じ服だね」を卒業できる＆コーデのレパートリーを増やすイベントなどの日に自分の持っている服から提案してほしい
   タンスの奥深くに眠っている服を明らかにし、断捨離できるようにする
   自分が着なくてもイメージできるようにしたい
4. コア機能（MVP範囲）
   ・ログイン機能
   ・着用記録（AIが着用している服のカテゴリを判断、その日着た服の写真撮る→クローゼットに登録してあるものの中からどれが該当するかを登録する→統計をとる）
   ・統計
   →色合いの統計（円グラフ）、季節ごとの着ている服、着た服の回数（ランキング5位まで）（カテゴリ別）、あまり着ていない服を提案（機能）
   ・カメラ機能
   ・アイテム登録機能機能
   （服単品の写真を撮る→クローゼットに登録する）
   ・（ログイン時に統計からおすすめの着用アイテム（１アイテムくらい？）が提示される。）
   ・（統計できたら：位置情報からその日の最高気温と最低気温を参照して来ていた服と一緒に保存、統計をとる）
   ・試着画像生成
   ・着ていない服の整理ができるようにAIが提案する
   ・マイページ
   →名前、アイコン、年齢、住まい（必須）：東京、何区（任意）品川区
   →AIが読み取る→元々のプロンプトにマイページの住まいを読み込んで天気予報を確認した上で提案してください。
   ・自分だけのクローゼットAIエージェント機能（質問して、旅行時の旅先の天気などを考慮した上でコーディネートの提案など）
